# Greedy prompts for L4, one per line. Blank lines and lines opening with a
# hash are skipped.
#
# Written as continuations, not as questions. E4B at the pinned revision is a
# base model: asked "What is the capital of France?" it does not answer, and a
# reader who expects one will read a fluent non-answer as a defect. This was
# measured rather than assumed -- a 16-token greedy probe on "The capital of
# France is" returned " a city that is full of history and culture", which is
# a healthy base model and a weak prompt at the same time.
#
# Order is load-bearing. SIZE takes a prefix of this list -- 2 prompts for
# quick, 8 for standard, 32 for deep -- so a quick run reproduces the first
# rows of a deep run exactly. Append to the end; never insert.
#
# Ordinary modern prose on purpose. Off-distribution input widens the gap
# between two implementations measurably: the same prompt captured without a
# BOS gave rel_L2 3.3e-5 where the in-distribution version gave 5.0e-6.
