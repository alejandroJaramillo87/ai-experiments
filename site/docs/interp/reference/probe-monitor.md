# probe-monitor

Generated by `make site-gen` from `python -m interp probe-monitor --help`. Do not edit this page; edit the parser in `interp/commands/probe_monitor.py` and regenerate.

Aggregate a window of served-request logs into a probe report (W4).

Reads the scores the serving process already took; runs no model, needs no GPU, and does not care whether inference is up. Exit codes: 0 success, 1 failure, 2 invalid usage.

## Usage

```text
usage: python -m interp probe-monitor [-h] [--window WINDOW] [--probes PROBES]
                                      [--log-dir LOG_DIR]
                                      [--monitor-root MONITOR_ROOT]
                                      [--max-records MAX_RECORDS]
```

## Flags

| Flag | Description | Default |
|------|-------------|---------|
| `--window WINDOW` | e.g. 7d or 12h | `7d` |

| `--max-records MAX_RECORDS` |  |  |
