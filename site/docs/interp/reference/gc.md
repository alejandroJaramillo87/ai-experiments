# gc

Generated by `make site-gen` from `python -m interp gc --help`. Do not edit this page; edit the parser in `interp/commands/interp_gc.py` and regenerate.

Delete validated activation captures, keeping manifests (P4-D2 retention).

Captures are regenerable cache: downstream SAE runs flag a capture --validated, and this tool deletes flagged captures oldest-first. Manifests survive deletion for provenance. Exit codes: 0 success, 1 failure, 2 invalid usage.

## Usage

```text
usage: python -m interp gc [-h] [--root ROOT] [--dry-run]
                           [--mark-validated MARK_VALIDATED]
```

## Flags

| Flag | Description | Default |
|------|-------------|---------|
| `--root ROOT` | activations tree to collect | `/mnt/ai-data/interp/activations` |
| `--dry-run` | list what would be deleted without deleting |  |
| `--mark-validated MARK_VALIDATED` | flag one capture directory deletable instead of collecting |  |
