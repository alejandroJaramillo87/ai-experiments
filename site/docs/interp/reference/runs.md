# runs

Generated by `make site-gen` from `python -m interp runs --help`. Do not edit this page; edit the parser in `interp/commands/runs.py` and regenerate.

List recent runs from the observability catalog. Reads ${OBS_LOG_DIR}/interp/runs.jsonl, the per-CLI catalog one summary line is appended to when a command ends.

## Usage

```text
usage: python -m interp runs [-h] [-n LIMIT] [--failed] [--all] [--json]
```

## Flags

| Flag | Description | Default |
|------|-------------|---------|
| `-n, --limit LIMIT` | most recent runs shown (default 20; 0 or less shows all) | `20` |
| `--failed` | only runs with a nonzero exit code |  |
| `--all` | include invocations of the runs command itself |  |
| `--json` | emit the selected records as JSON on stdout |  |
