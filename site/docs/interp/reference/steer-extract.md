# steer-extract

Generated by `make site-gen` from `python -m interp steer-extract --help`. Do not edit this page; edit the parser in `interp/commands/steer_extract.py` and regenerate.

Extract a steering direction and export it as control-vector safetensors (W1).

Thin CLI over interp.steering.{extract,export}. diff_means reads a capture directory and needs no model or GPU; sae_row reads a pretrained SAE. Exit codes: 0 success, 1 failure, 2 invalid usage.

## Usage

```text
usage: python -m interp steer-extract [-h] [--method {diff_means,sae_row}]
                                      [--capture CAPTURE] [--layers LAYERS]
                                      [--model MODEL] [--revision REVISION]
                                      [--model-hash MODEL_HASH]
                                      [--sae-release SAE_RELEASE]
                                      [--sae-id SAE_ID] [--feature FEATURE]
                                      [--layer LAYER] --out OUT
```
