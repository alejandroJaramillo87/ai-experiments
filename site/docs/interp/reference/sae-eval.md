# sae-eval

Generated by `make site-gen` from `python -m interp sae-eval --help`. Do not edit this page; edit the parser in `interp/commands/sae_eval.py` and regenerate.

Evaluate a trained SAE against its capture (interp Phase 4 P4-D3).

Core metric set — explained variance, L0, and optionally delta-LM-loss — written as eval_report.json in the SAE run directory. Delta-LM-loss runs subject-model forward passes (GPU, inference down); the reconstruction metrics need only the cached activations. Exit codes: 0 success, 1 failure, 2 invalid usage.

## Usage

```text
usage: python -m interp sae-eval [-h] --sae-dir SAE_DIR --capture-dir
                                 CAPTURE_DIR [--max-tokens MAX_TOKENS]
                                 [--delta-loss-texts DELTA_LOSS_TEXTS]
```

## Flags

| Flag | Description | Default |
|------|-------------|---------|
| `--sae-dir SAE_DIR` | SAE run directory (/mnt/ai-data/interp/saes/&lt;name&gt;) | required |
| `--capture-dir CAPTURE_DIR` | P4-D2 capture directory to evaluate against | required |
| `--max-tokens MAX_TOKENS` | activation rows sampled for the reconstruction metrics | `1000000` |
| `--delta-loss-texts DELTA_LOSS_TEXTS` | JSONL of texts for delta-LM-loss; omit to skip the forward passes |  |
