# sae-train

Generated by `make site-gen` from `python -m interp sae-train --help`. Do not edit this page; edit the parser in `interp/commands/sae_train.py` and regenerate.

Train an SAE from a P4-D2 activation capture (interp Phase 4 P4-D3).

Workbench batch job (GPU, inference down): wraps SAELens's training runner under the D9 lock, D10 watchdog, and D6 tracking, gated on the capture manifest. Exit codes: 0 success, 1 failure, 2 invalid usage.

## Usage

```text
usage: python -m interp sae-train [-h] --recipe RECIPE [--override OVERRIDE]
                                  [--validated]
```

## Flags

| Flag | Description | Default |
|------|-------------|---------|
| `--recipe RECIPE` | SAE recipe YAML (training/recipes/interp/) | required |
| `--override OVERRIDE` | dotlist override, repeatable (sae.train_tokens=2000000) |  |
| `--validated` | on success, flag the consumed capture deletable for interp-gc |  |
