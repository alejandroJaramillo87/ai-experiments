# probe-export

Generated by `make site-gen` from `python -m interp probe-export --help`. Do not edit this page; edit the parser in `interp/commands/probe_export.py` and regenerate.

Export a registered probe as the safetensors image the harness loads (W3).

probe-train registers a probe as probe.npz, which is the training format and is read only by Python. The rust harness scores probes in the process that answers a request, and its reader takes a safetensors image plus a JSON sidecar (schemas/probe_artifact.json). This is the step between the two: it loads the registered probe with its hash checked, then writes the pair.

CPU work, no model and no GPU. Exit codes: 0 success, 1 failure, 2 invalid usage.

## Usage

```text
usage: python -m interp probe-export [-h] --probe PROBE [--out OUT]
```

## Flags

| Flag | Description | Default |
|------|-------------|---------|
| `--probe PROBE` | registered probe directory, e.g. /mnt/ai-data/interp/probes/&lt;name&gt; | required |
| `--out OUT` | output image path (default probe.safetensors inside the probe directory) |  |
