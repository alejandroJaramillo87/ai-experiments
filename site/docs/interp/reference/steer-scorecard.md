# steer-scorecard

Generated by `make site-gen` from `python -m interp steer-scorecard --help`. Do not edit this page; edit the parser in `interp/commands/steer_scorecard.py` and regenerate.

Run the three-arm steering scorecard against the live services (W1).

Thin CLI over interp.steering.scorecard. Host-side, serving-dependent: it recreates the subject service between arms via the make steer targets and refuses to run while the GPU lock is held. Exit codes: 0 success, 1 failure, 2 invalid usage.

## Usage

```text
usage: python -m interp steer-scorecard [-h] --vector VECTOR --attribute
                                        ATTRIBUTE
                                        [--behavior-prompts BEHAVIOR_PROMPTS]
                                        [--neutral-prompts NEUTRAL_PROMPTS]
                                        [--system-prompt SYSTEM_PROMPT]
                                        [--subject-url SUBJECT_URL]
                                        [--judge-url JUDGE_URL]
                                        [--judge-model JUDGE_MODEL]
                                        [--scales SCALES]
                                        [--max-tokens MAX_TOKENS]
                                        [--judge-max-tokens JUDGE_MAX_TOKENS]
                                        [--layer-range "START END"]
                                        [--perplexity-cmd PERPLEXITY_CMD]
```

## Flags

| Flag | Description | Default |
|------|-------------|---------|
| `--vector VECTOR` | vector directory (host path) | required |
| `--attribute ATTRIBUTE` | behavior the judge scores | required |
| `--behavior-prompts BEHAVIOR_PROMPTS` |  | `interp/steering/prompts/behavior_honesty.jsonl` |
| `--neutral-prompts NEUTRAL_PROMPTS` |  | `interp/steering/prompts/neutral.jsonl` |
| `--system-prompt SYSTEM_PROMPT` | tuned system-prompt JSON with recorded iterations | `interp/steering/prompts/system_prompt_honesty.json` |
| `--subject-url SUBJECT_URL` | the steered service (default: the harness entry in common/serving.py) | `http://127.0.0.1:8005` |
| `--judge-url JUDGE_URL` | the judge service (default: llama-cpu in common/serving.py) | `http://127.0.0.1:8001` |
| `--judge-model JUDGE_MODEL` |  | `default` |
| `--scales SCALES` | comma-separated steering scales | `0.5,1,2` |
| `--max-tokens MAX_TOKENS` | subject budget | `256` |
| `--judge-max-tokens JUDGE_MAX_TOKENS` | judge budget for the JSON verdict; the judge runs with thinking off | `512` |
| `--layer-range "START END"` | inclusive 0-based block band the vector is applied in; one argument holding two numbers, as make steer-up LAYER_RANGE takes it |  |
| `--perplexity-cmd PERPLEXITY_CMD` | optional command run per arm, recorded verbatim (e.g. scripts/benchmark/test_perplexity.sh) |  |
