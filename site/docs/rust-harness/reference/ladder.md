# ladder

Generated by `make site-gen` from `ladder --help`. Do not edit this page; edit the flag table in `rust-harness/runtime/src/bin/ladder.rs` and regenerate.

Run the seven-rung correctness gate against a transformers reference.

## Usage

```text
usage: ladder --model <checkpoint-dir> --reference <reference-dir> [--size quick|standard|deep] [--rung L0|L1|L2|L3|L4|L5|L6] [--dot <kind>] [--batch stepped|whole|<n>] [--threads <n>] [--text-only] [--single-thread]
```

## Options

| Flag | Description |
|------|-------------|
| `--help` | print this help and exit |
| `-h` | print this help and exit |
| `--model <checkpoint-dir>` | the checkpoint to climb; required |
| `--reference <reference-dir>` | directory of transformers reference artifacts to compare against; required |
| `--size quick\|standard\|deep` | how much corpus the perplexity and greedy rungs read |
| `--rung L0\|L1\|L2\|L3\|L4\|L5\|L6` | climb one rung rather than all seven |
| `--dot <kind>` | the dot-product kernel; every kind is bit-identical |
| `--batch stepped\|whole\|<n>` | how many positions one forward pass covers |
| `--threads <n>` | row-split width; the tables are bit-identical at every width |
| `--text-only` | treat a multimodal checkpoint as its text tower |
| `--single-thread` | shorthand for --threads 1, for rr, which serializes threads anyway |
