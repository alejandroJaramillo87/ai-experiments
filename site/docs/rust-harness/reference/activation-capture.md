# activation-capture

Generated by `make site-gen` from `activation-capture --help`. Do not edit this page; edit the flag table in `rust-harness/runtime/src/bin/activation-capture.rs` and regenerate.

```text
usage: activation-capture --model <checkpoint-dir> --dataset <examples.jsonl> --layers <l0,l1,...> --out <dir> [--text-only] [--single-thread]

Write last-token residual activations for the requested layers in the
interp capture shard format.

Options:
  --help
      print this help and exit
  -h
      print this help and exit
  --model <checkpoint-dir>
      the checkpoint to capture from; required
  --dataset <examples.jsonl>
      one JSON object per line, each with a text field and a label; required
  --layers <l0,l1,...>
      decoder layers to tap, comma separated and distinct; required
  --out <dir>
      capture directory to write shards, examples.jsonl and manifest.json into; required
  --text-only
      treat a multimodal checkpoint as its text tower
  --single-thread
      run the row split on one thread; results are bit-identical at every width
```
