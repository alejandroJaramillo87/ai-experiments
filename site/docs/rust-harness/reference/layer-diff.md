# layer-diff

Generated by `make site-gen` from `layer-diff --help`. Do not edit this page; edit the flag table in `rust-harness/runtime/src/bin/layer-diff.rs` and regenerate.

Report per-layer divergence of the residual stream against a reference capture, and pass or fail it against the tolerances.

## Usage

```text
usage: layer-diff --model <checkpoint-dir> --reference <capture.json> [--cosine-floor <f>] [--rel-l2-ceiling <f>] [--text-only] [--single-thread]
```

## Options

| Flag | Description |
|------|-------------|
| `--help` | print this help and exit |
| `-h` | print this help and exit |
| `--model <checkpoint-dir>` | the checkpoint to run; required |
| `--reference <capture.json>` | the reference capture to compare against; required |
| `--cosine-floor <f>` | lowest per-layer cosine similarity that still passes |
| `--rel-l2-ceiling <f>` | highest per-layer relative L2 error that still passes |
| `--text-only` | treat a multimodal checkpoint as its text tower |
| `--single-thread` | run the row split on one thread; the figures are unchanged |
