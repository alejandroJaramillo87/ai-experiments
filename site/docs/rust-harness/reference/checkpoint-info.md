# checkpoint-info

Generated by `make site-gen` from `checkpoint-info --help`. Do not edit this page; edit the flag table in `rust-harness/runtime/src/bin/checkpoint-info.rs` and regenerate.

Dump a checkpoint's config and tensor table, then the architecture summary and the CPU backend's compatibility verdict.

## Usage

```text
usage: checkpoint-info [--check] [--text-only] <checkpoint-dir>
```

## Options

| Flag | Description |
|------|-------------|
| `--help` | print this help and exit |
| `-h` | print this help and exit |
| `--check` | exit 1 when the checkpoint is unsupported, rather than reporting and exiting 0 |
| `--text-only` | treat a multimodal checkpoint as its text tower |
