# harness

Generated by `make site-gen` from `harness --help`. Do not edit this page; edit the flag table in `rust-harness/harness/src/cli.rs` and regenerate.

Run a coding task, a chat REPL, or an HTTP server against a local Gemma 4 checkpoint on the CPU backend.

## Usage

```text
usage: harness --model <checkpoint-dir> [--tokenizer <path.json>] [--record <path>] [--trace-chrome <path>] [--trace-level <info|debug|trace>] [--control-vector <path.safetensors>] [--control-vector-scale <f>] [--control-vector-layer-range "<start> <end>"] [--probe <path.safetensors>] [--interp-log <dir>] [--probe-out <path>] [--alignment-out <path>] [--temperature <f>] [--top-p <f>] [--top-k <n>] [--seed <n>] [--max-tokens <n>] [--context <n>] [--compact-at <f>] [--text-only] [--single-thread] [--deep] [--serve-addr <ip>] (--chat | --serve <port> | --status | <task description>)
```

## Mode

| Flag | Description |
|------|-------------|
| `--chat` | interactive REPL instead of a one-shot task; takes no task text |
| `--serve <port>` | serve /v1/chat/completions and /v1/health instead of running a task; the sampling flags become per-request defaults that a request may override, and no task text is taken |
| `--status` | report what this invocation would fail on and exit, without loading the model: the checkpoint, the backend's verdict on it, each interp artifact, and the directories written to; exit 1 if anything would stop the run, and no run record is written because a query is not a run |

## Model

| Flag | Description |
|------|-------------|
| `--model <checkpoint-dir>` | config.json and model.safetensors for the CPU backend; a path to the weights file resolves to its directory |
| `--tokenizer <path.json>` | tokenizer.json to use instead of the one beside the checkpoint |
| `--context <n>` | cap the context budget below the model's trained window; max_position_embeddings is both the default and the maximum |
| `--text-only` | load the text stack of a multimodal checkpoint and decline its audio and vision towers; required rather than implied, so nobody runs a model text-blind without having said so |

## Sampling

| Flag | Description |
|------|-------------|
| `--temperature <f>` | softmax temperature; 0 selects greedy decoding (default 0.8) |
| `--top-p <f>` | nucleus mass kept, in (0, 1] (default 0.95); no effect when temperature is 0 |
| `--top-k <n>` | rank cutoff applied before top-p, keeping at most the n most probable tokens of the masked support; 0 is rejected rather than read as disabled (default no rank cutoff); no effect when temperature is 0 |
| `--seed <n>` | sampler seed; the same seed replays a run exactly (default 0) |
| `--max-tokens <n>` | per-turn generation budget (default 256) |
| `--compact-at <f>` | automatic-compaction threshold as a fraction of the context budget, in (0, 1] (default 0.8) |

## Interpretability

| Flag | Description |
|------|-------------|
| `--control-vector <path.safetensors>` | steering directions from interp/steering/export.py, one block.&lt;index&gt; tensor per steered decoder block, added to that block's output residual |
| `--control-vector-scale <f>` | multiplier on the steering directions (default 1.0); requires --control-vector |
| `--control-vector-layer-range "<start> <end>"` | inclusive 0-based block range; directions outside it are dropped at load; requires --control-vector |
| `--probe <path.safetensors>` | linear probe (interp/probes/export.py layout) scored in-band at every position of its layer; the .json sidecar beside it carries the layer, site and threshold, and is required |
| `--interp-log <dir>` | under --serve, append one JSONL record per completed request to &lt;dir&gt;/harness/YYYY-MM-DD.jsonl, carrying the request, the reply, and the probe scores taken while answering it; this is what interp's probe monitor reads; no effect when there is no --serve |
| `--probe-out <path>` | JSONL file for flagged positions (default probe-flags.jsonl in the working directory) |
| `--alignment-out <path>` | JSONL file mapping every position to the byte span of output text it produced, the forward pass that computed it, and the probe score taken there; off by default because it makes the model record every pass |

## Serving

| Flag | Description |
|------|-------------|
| `--serve-addr <ip>` | bind address for --serve; only a container needs to set it, and must (default 127.0.0.1); requires --serve |

## Diagnostics

| Flag | Description |
|------|-------------|
| `--record <path>` | wrap the model in the flight recorder, appending every forward call to a JSONL file replayable as a MockModel script |
| `--trace-chrome <path>` | write a Perfetto-loadable trace of the span timeline; no subscriber is installed otherwise, so spans cost nothing |
| `--trace-level <info\|debug\|trace>` | how deep the trace goes: info is the session-level spans, debug adds one span per layer and block of the forward pass and of the load, trace adds one per kernel call (default debug); requires --trace-chrome |
| `--single-thread` | run the CPU backend's row split at width one; not a numerics switch, since the split is bit-identical at every width, but rr serializes threads anyway |
| `--deep` | under --status, hash the weights and compare the digest against what each interp artifact records; opt-in because it reads the whole checkpoint, which is the one part of a preflight that is not fast; requires --status; no effect when there is no interp artifact to check |
| `--help` | print this help on stdout and exit |
| `-h` | synonym for --help |
| `--version` | print the harness version on stdout and exit |
| `-V` | synonym for --version |
