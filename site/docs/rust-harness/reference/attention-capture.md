# attention-capture

Generated by `make site-gen` from `attention-capture --help`. Do not edit this page; edit the flag table in `rust-harness/runtime/src/bin/attention-capture.rs` and regenerate.

Write post-softmax attention weights for the requested layers and query heads over one prompt.

## Usage

```text
usage: attention-capture --model <checkpoint-dir> --prompt <text> --layers <l0,l1,...> --heads <h0,h1,...> --out <dir> [--text-only] [--single-thread]
```

## Options

| Flag | Description |
|------|-------------|
| `--help` | print this help and exit |
| `-h` | print this help and exit |
| `--model <checkpoint-dir>` | the checkpoint to capture from; required |
| `--prompt <text>` | the single prompt the attention is captured over; required |
| `--layers <l0,l1,...>` | decoder layers to capture, comma separated and distinct; required |
| `--heads <h0,h1,...>` | query heads to capture, comma separated and distinct; required |
| `--out <dir>` | directory to write the attention shards and manifest into; required |
| `--text-only` | treat a multimodal checkpoint as its text tower |
| `--single-thread` | run the row split on one thread; results are bit-identical at every width |
